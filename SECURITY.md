# Security policy

Do not open a public issue for a suspected vulnerability.

Report it through [GitHub private vulnerability reporting](https://github.com/tansohq/credit-estimator/security/advisories/new).
Include affected package and version, reproduction steps, impact, and any known
mitigation. Avoid including real customer data or active credentials.

Use public issues for ordinary defects that do not expose data, credentials,
or execution paths.
